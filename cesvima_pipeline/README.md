# Production pipeline

YAML configs, Slurm workers, and aggregation scripts for the high-dimensional
FinSTOD campaign. Run from the **repository root** (the workers import `stod_nd`).

See the root README for the local smoke test, config naming, and Slurm usage.
Use `prod_hh_energy_*_v2.yaml` for the Hénon–Heiles energy sweep.
